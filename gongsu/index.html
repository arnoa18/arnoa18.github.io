공수계산수첩

일용직·현장직을 위한 공수 달력

한 번 탭으로 공수 입력

  • 현장과 공수를 골라 두고 날짜만 누르면 바로 입력
  • 0.5·1.5·2공수와 직접 입력
  • 하루에 여러 현장도 기록

받을 돈 자동 계산

  • 현장별 단가, 잔업·주차·월차 등 구분별 단가
  • 3.3%·일용근로소득세·고용보험·직접 입력 세율
  • 월별·연간 합계, 식대·가불 같은 수입·지출

쓰기 편하게

  • 큰 글자, 광고는 위쪽 배너 하나뿐 (한 번 결제하면 광고 제거)
  • 메모 검색, 문자·엑셀 내보내기, 백업 파일
  • 알림·금액 숨기기, 기록은 내 폰 안에만 저장
